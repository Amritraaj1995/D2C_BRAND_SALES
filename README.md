# 📊 Sales Performance Dashboard – Excel

## 📌 Project Overview

This project is an interactive **Sales Performance Dashboard built using Microsoft Excel**.

The dashboard provides a clear overview of sales performance across different **categories, regions, and months**, helping identify sales trends and high- and low-performing areas.

This is my **first Excel dashboard project**, created as part of my Data Analyst learning journey.

---

## 🎯 Project Objective

The main objective of this project is to:

- Analyze overall sales and profit performance
- Compare sales across different product categories
- Analyze monthly sales trends
- Compare regional sales performance
- Identify high- and low-performing categories and regions
- Present business insights through an interactive dashboard

---

## 🛠️ Tools & Skills Used

- **Microsoft Excel**
- Pivot Tables

## 🔍 Key Insights

### 📦 Category Analysis
- Electronics is the **top-performing category**, generating the highest sales.
- Apparel ranks second in terms of sales.
- Beauty records the lowest sales among the categories.

### 📈 Monthly Sales Trend
- Sales remained relatively stable during January and February.
- March recorded the **highest sales**.
- April experienced a **sharp decline in sales**, indicating a need to investigate the reason behind the drop.

### 🌎 Regional Analysis
- **East is the highest-performing sales region**.
- West records the lowest sales compared with North and South.
- The West region therefore has potential scope for improvement.
